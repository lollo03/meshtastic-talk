# Welcome to Slidev POuL template!

To start the slide show install `node.js` and run:

- `npm install`
- `npm dev`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see the changes.

## Layouts

- `intro-classic`
- `outro-classic`
- `center` (centered vertically and horizontally)
- `center-h` (centered horizontally)
- `steps`
- `branded-header` POuL branded content layout

Learn more about Slidev's default layouts at the [documentation](https://sli.dev/builtin/layouts).

## Components

- `SlidesQRCode`
- `NoteBox` (with attribute `level={Warning, Info, Alert}`)
- `Map` a leaflet.js map pointing to HQs

Learn more about Slidev's default components at the [documentation](https://sli.dev/builtin/components).
